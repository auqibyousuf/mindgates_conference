# Architecture

> Generated by Antigravity on 2026-05-15

## Overview
Conference Event is a modern Next.js application built for a scholarly organization. It facilitates national and international conferences, academic publishing, and honors research excellence. The application follows a data-driven approach where content is managed through JSON files, allowing for easy updates and maintenance.

## System Diagram
```
[User Browser]
      |
      v
[Next.js App Router (Vercel/Node.js)]
      |
      +-- [Components (React/Lucide Icons)]
      |
      +-- [Data Layer (JSON files in src/data)]
      |
      +-- [Styles (Tailwind CSS 4 + custom Glassmorphism)]
```

## Components

### Core UI Components
- **Location:** `src/components/`
- **Purpose:** Reusable UI elements like `ConferenceCard`, `BookCard`, `AwardCard`, and `GlassContainer`.
- **Styling:** Uses Tailwind CSS 4 with custom "Academic Glass" utility classes defined in `globals.css`.

### Layout Components
- **Location:** `src/components/layout/`
- **Purpose:** Global components like `Navbar` and `Footer` that provide consistent navigation and branding across the site.

### App Router (Pages)
- **Location:** `src/app/`
- **Purpose:** Route handling and page-level logic. Each subdirectory (e.g., `conferences`, `awards`, `books`) corresponds to a public route.

## Data Flow
1. **Static Data:** Content for conferences, books, awards, and site configuration is stored in `src/data/*.json`.
2. **Page Loading:** Next.js pages import these JSON files directly (Server-Side or Static Generation).
3. **Rendering:** Data is passed as props to specialized components (e.g., `ConferenceCard`) for display.

## Integration Points
| External Service | Type | Purpose |
|------------------|------|---------|

## Conventions
- **Naming:** PascalCase for components, camelCase for variables and JSON keys.
- **Structure:** App Router architecture with a clear separation between data, components, and pages.
- **Styling:** Utility-first with Tailwind CSS 4, augmented by custom "Academic Glass" tokens for premium aesthetics.
